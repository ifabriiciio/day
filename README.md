# Day · Xatspace

Sitio de perfil de Day, creado con React y Vite.

## Desarrollo local

```bash
npm ci
npm run dev
```

## Publicación

El sitio se construye y publica automáticamente en GitHub Pages al subir cambios a `main`.

Sitio: https://ifabriiciio.github.io/day/

El repositorio es público: el código fuente y los recursos incluidos en `diseños/` son accesibles para cualquiera.
